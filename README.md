## 🚀 Cómo publicar en GitHub Pages / How to publish on GitHub Pages

### Paso 1: Crear el repositorio / Step 1: Create the repository

1. Ve a [GitHub](https://github.com) e inicia sesión
2. Haz clic en el botón **"New"** (verde) para crear un nuevo repositorio
3. Nombra el repositorio como: `tu-usuario.github.io` 
   - Por ejemplo: `geronimolelan.github.io`
   - **Importante**: Debe ser exactamente tu nombre de usuario + `.github.io`
4. Marca el repositorio como **Público** (Public)
5. Haz clic en **"Create repository"**

---

1. Go to [GitHub](https://github.com) and sign in
2. Click the **"New"** button (green) to create a new repository
3. Name the repository: `your-username.github.io`
   - For example: `geronimolelan.github.io`
   - **Important**: It must be exactly your username + `.github.io`
4. Mark the repository as **Public**
5. Click **"Create repository"**

### Paso 2: Subir los archivos / Step 2: Upload the files

**Opción A: Usando la interfaz web de GitHub / Option A: Using GitHub web interface**

1. En la página del repositorio recién creado, haz clic en **"uploading an existing file"**
2. Arrastra los 3 archivos:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Escribe un mensaje de commit: "Initial portfolio commit"
4. Haz clic en **"Commit changes"**

**Opción B: Usando Git desde la terminal / Option B: Using Git from terminal**

```bash
# Clona el repositorio
git clone https://github.com/tu-usuario/tu-usuario.github.io.git
cd tu-usuario.github.io

# Copia los 3 archivos (index.html, styles.css, script.js) a esta carpeta

# Agrega los archivos
git add .

# Haz commit
git commit -m "Initial portfolio commit"

# Sube los cambios
git push origin main
```

### Paso 3: Configurar GitHub Pages / Step 3: Configure GitHub Pages

1. Ve a la pestaña **"Settings"** de tu repositorio
2. En el menú lateral, busca **"Pages"**
3. En **"Source"**, selecciona **"Deploy from a branch"**
4. En **"Branch"**, selecciona **"main"** y **"/ (root)"**
5. Haz clic en **"Save"**

### Paso 4: ¡Visita tu portfolio! / Step 4: Visit your portfolio!

Después de 1-2 minutos, tu portfolio estará disponible en:
```
https://tu-usuario.github.io
```

After 1-2 minutes, your portfolio will be available at:
```
https://your-username.github.io
```
