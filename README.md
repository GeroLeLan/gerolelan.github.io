## 📝 Personalización / Customization

Para actualizar el contenido del portfolio, simplemente edita los archivos:

To update the portfolio content, simply edit the files:

- **index.html**: Contenido y estructura / Content and structure
- **styles.css**: Estilos y colores / Styles and colors
- **script.js**: Funcionalidades e interacciones / Functionalities and interactions

### Cambiar colores / Change colors

En `styles.css`, modifica las variables CSS al inicio del archivo:

In `styles.css`, modify the CSS variables at the beginning of the file:

```css
:root {
    --accent: #3b82f6;  /* Color principal / Main color */
    --accent-dark: #2563eb;  /* Color oscuro / Dark color */
    /* ... más variables ... / ... more variables ... */
}
```
